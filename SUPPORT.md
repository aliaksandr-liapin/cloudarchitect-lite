# Getting help

- **Installation problems:** start with the troubleshooting section of the [installation guide](docs/operations/installation.md#troubleshooting).
- **Bugs:** open a [bug report](https://github.com/aliaksandr-liapin/cloudarchitect-lite/issues/new?template=bug.yml) with steps to reproduce. Never paste API keys, setup codes or private project files.
- **Ideas and feature requests:** open a [feature request](https://github.com/aliaksandr-liapin/cloudarchitect-lite/issues/new?template=feature.yml).
- **Security issues:** do not open a public issue; follow [SECURITY.md](SECURITY.md).

There is no guaranteed response time during pre-1.0 development.
